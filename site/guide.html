1. 下载与安装

在 Releases 页面选择一种：

文件适合说明
Lyrscape_x.y.z_x64-setup.exe大多数人安装到 %LOCALAPPDATA%\Lyrscape，不需要管理员权限，创建开始菜单快捷方式。缺少 WebView2 运行时会自动下载。
Lyrscape_x.y.z_x64_portable.zipU 盘 / 不想安装解压到任意可写的文件夹后运行 Lyrscape.exe。插件保存在 exe 旁的 plugins 文件夹。需要系统已有 WebView2（Windows 11 自带）。

安装时可以修改安装位置；请选择你有写入权限的文件夹（默认位置即可），不要装到 C:\Program Files。

2. 更新与卸载

  • 更新：下载新版安装包直接运行，它会先移除旧版程序再安装。设置、选择的渲染器和已安装的插件都会保留。Lyrscape 正在运行时，安装包会提示先关闭它。
  • 卸载：Windows 设置 → 应用 → Lyrscape → 卸载。卸载页面的「删除应用数据」勾选后，会一并删除设置、WebView 缓存和已安装的插件（%LOCALAPPDATA%\io.github.kevin2106.lyrscape）；不勾选则保留，重装后还在。
  • 便携版：替换文件夹里的 Lyrscape.exe 即可更新，保留 plugins 文件夹。

3. 连接 AMLL Player

  1. 打开 Lyrscape 的「歌词」页，在「播放来源」中选择 AMLL，端口保持 11444，点「启动服务」。状态显示「等待连接」。
  2. 在 AMLL Player（或支持 AMLL WS Protocol 的播放器插件，如网易云的 AMLL WS Connector）里，把连接地址设为 ws://localhost:11444 并启用。
  3. 状态变为「已连接」后，曲目、歌词和进度会实时同步。播放器开启音频发送时，「特效 › 跟随节拍」也会生效。

连不上时，先看「调试 › AMLL 原始数据」里有没有「connected」和 setMusic / setLyric 消息（见 调试）。端口被占用时换一个端口，并在播放器里同步修改。

4. 系统媒体（SMTC）与在线歌词

不用 AMLL 时，Lyrscape 也可以读取 Windows 的「系统媒体控制」——就是按音量键时弹出的媒体卡片里显示的曲目。Spotify、QQ 音乐、浏览器里的网页播放器等大多支持。

  1. 在「歌词」页的「播放来源」中选择 系统媒体，然后照常在播放器里放歌。
  2. Lyrscape 读到曲名、歌手和进度后，会自动从 LRCLIB 和网易云音乐搜索歌词，优先使用带时间的歌词；网易云有翻译时一并显示为译文。
  3. 找错了就在下方候选列表里点另一首，这个选择会被记住；「重新搜索」会忽略之前的结果。
  4. 同时开着几个播放器时，在「媒体会话」里指定要读取的应用。
搜索时会把曲名、歌手、专辑和时长发送给 LRCLIB / 网易云音乐。只有选择「系统媒体」作为播放来源时才会联网；在「全部插件 › 系统媒体（SMTC）」中可以只用其中一家、关闭网易云译文或调整歌词偏移（歌词早了调大，晚了调小）。

部分应用（尤其是浏览器页面）不报告播放进度，这时歌词无法跟随时间。搜索与匹配的过程可以在「调试 › SMTC 与在线歌词」中查看。

5. 桌面歌词

  • 右上角「桌面歌词」开关显示透明歌词窗口；「设置」页可以开关置顶、鼠标穿透和调整边框。
  • 关闭鼠标穿透后，拖动歌词中间移动窗口，拖动左右边缘调整宽度；高度自动适配。
  • 全局快捷键（可在「设置」中修改）在任何程序里都能显示 / 隐藏歌词、切换穿透。
  • 关闭主窗口会最小化到托盘，桌面歌词继续显示；从托盘图标退出。

6. 安装插件

  1. 在 插件 页下载 .lyrx 文件。
  2. Lyrscape →「插件 › 全部插件」→「导入插件」选择文件，或者直接把文件拖进窗口。
  3. 确认对话框会显示插件 ID、作者、大小和「完整性：已校验」。确认后插件立即在主窗口和桌面歌词中运行，不需要重启。
  4. 渲染器插件到「插件 › 渲染器」选用；特效插件在「插件 › 特效」中开关。
  • 更新插件：导入同一 ID 的新版本即可，配置和选择保留；失败会自动恢复旧版。
  • 卸载插件：在插件详情中点「卸载」。如果它是当前渲染器，会回到普通文字。
  • 导出：插件详情 →「导出」，连同当前配置保存为 .lyrx（在「下载」文件夹）。
插件与应用同权限运行，没有沙箱，可以读取歌词、播放状态和设置。只安装你信任的来源提供的插件。

8. 调试与反馈问题

左侧「应用 › 调试」页在正式版中也可用：

页签能看到什么
播放播放来源、AMLL 服务状态、曲目、播放器最后报告的位置与「采样年龄」、时间轴计算出的位置、当前行。
AMLL 原始数据播放器发来的每条消息（解码后的 JSON）、连接 / 断开事件和处理失败的原因。可隐藏高频的 progress、暂停记录、复制全部。
SMTC 与在线歌词系统媒体会话的变化、每次歌词搜索的查询、候选与匹配度、命中 / 缓存 / 手动选择和失败原因。
歌词解析当前歌词被解析成了什么：时间模式、行数、逐字片段、识别的语言，以及每一行的逐字时间。可以粘贴歌词「试解析」而不替换当前歌词。
节拍与音频节拍检测的 BPM、置信度、相位与脉冲曲线，频带 / 音级 / 波形，以及最近一帧 PCM 的来源、序号、丢帧与峰值。
插件每个插件的状态、来源、提供的服务与错误。
事件未捕获的错误、插件加载失败。

报告问题时，点右上角「复制诊断信息」，粘贴到 Issues。诊断信息包含版本、播放状态、歌词统计、插件状态和最近的 AMLL 消息（不含高频进度），不包含歌词正文的整份文档；如果最近的 setLyric 消息里有你不想公开的歌词，请先删掉。

9. 编写插件

插件是一个导出 manifest 和 Plugin 对象的 ES 模块，用 npm run plugin:pack 打包成 .lyrx。完整说明见仓库中的 插件编写手册，示例见 examples/plugins/wave/。想让插件出现在本站的插件页，提交 PR 把入口文件加到 site/gallery.json。

10. 常见问题

导入插件提示「完整性校验失败」

文件在下载或编辑后被改动了。重新下载；自己修改过的插件请用 npm run plugin:pack 重新打包。

插件无法安装 / 提示无法创建 plugins 目录

便携版放在了只读位置（如 C:\Program Files 或光盘）。移到可写的文件夹，或删掉 exe 旁的 plugins 文件夹改用应用数据目录。

桌面歌词不显示

确认右上角「桌面歌词」已打开；窗口可能在已断开的显示器上，可以在「设置」中关闭再打开，或按全局快捷键。

歌词出现得比演唱晚

看「调试 › 播放」的「采样年龄」：正常播放时它应该在几百毫秒内反复归零。如果一直增长，说明播放器没有持续发送进度。
