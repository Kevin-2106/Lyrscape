# 系统媒体（SMTC）adapter 与在线歌词

2026-10-18。插件 `official.adapter.smtc`（「系统媒体（SMTC）」，提供 `adapter.smtc@1`），仅 Windows 桌面版可用。

它读取 Windows 系统媒体传输控制（System Media Transport Controls）里的曲目和进度。发布 SMTC 会话的程序都可以用，例如 Spotify、QQ 音乐、浏览器、系统播放器、foobar2000 插件等。歌词按曲目信息在线搜索。

## 数据流

```
媒体应用 ──SMTC──▶ smtc.rs 轮询线程（0.5 秒） ──smtc-state 事件──▶ smtc.ts
                                                             │ 曲目变化（防抖 0.7 秒）
                                     lyrics_http_get（白名单）◀─┤
                                     LRCLIB / 网易云音乐 ──────▶ lyrics-online.ts 匹配 → LRC 解析
```

- **原生端**（`src-tauri/src/smtc.rs`）：
  - 只有选中「系统媒体」作为播放来源时才运行轮询线程。
  - 每 0.5 秒读取所选会话：默认跟随 Windows 的当前会话，也可以在来源面板里指定应用。读取的字段：
    - 标题、歌手、专辑；
    - 播放状态与速率；
    - 时间线：位置、时长，以及 `LastUpdatedTime`。
  - 只在有变化时发 `smtc-state` 事件。
- **进度**：SMTC 报告的位置对应 `LastUpdatedTime` 那一刻。前端换算成本窗口的单调时钟，由共享时间轴外推。
  - 和 AMLL 不同，SMTC 来源不设 5 秒外推上限，因为很多应用只在拖动或切歌时才更新时间线。
  - 暂停或继续时，如果时间线没有更新，就从当前外推出的位置接着算。
- **歌词搜索**（`src/plugins/lyrics-online.ts`，纯 TS，HTTP 可注入）：
  - LRCLIB：先用曲名、歌手、专辑和时长精确查询（`/api/get`），没有结果再搜索（`/api/search`）。
  - 网易云音乐：用「曲名 + 歌手」搜索（`/api/search/get/web`），对选中的候选再取歌词（`/api/song/lyric`）。
    - 译文（`tlyric`）作为同时间戳的下一行，合并成双语 LRC，由现有 LRC 解析器识别为译文。
    - 「作词 / 作曲」等署名行会去掉。
  - 匹配分数由三部分组成：
    - 曲名相似度，去掉括号注释、`feat.`，并统一全角/半角；
    - 歌手相似度，多个歌手时任一匹配即可；
    - 时长差：超过 15 秒直接排除。
  - 首选来源有少量加分。分数 0.6 以上的候选里，**优先使用带时间的歌词**；只有都不带时间时，才用纯文本（显示为静态歌词）。
- **缓存**：结果保存在 `localStorage`（`lyrscape.lyrics-cache.v1`，最多 60 首，控制窗口和桌面歌词窗口共用）。
  - 没找到的结果缓存 6 小时。
  - 「重新搜索」会跳过缓存。
  - 手动选择的候选会覆盖这首歌的缓存。
- **桌面歌词窗口**：和 AMLL 一样，overlay 运行一个后台实例。控制窗口关闭到托盘后，由它接管读取和搜索。

## 网络与隐私

- `lyrics_http_get` 只允许 `https://lrclib.net` 和 `https://music.163.com`：
  - 15 秒超时，响应最大 4 MB；
  - 通过 WinRT HttpClient 发出，遵循系统代理；
  - 网易云请求带 `Referer: https://music.163.com/`。
- 搜索时，曲名、歌手、专辑和时长会发送给所选的歌词服务；来源面板和插件说明里都写明了这一点。
- 只有选择「系统媒体」作为播放来源后才会联网。歌词来源可以在插件管理里改为只用其中一家。
- 网易云的接口不是公开 API，随时可能变化或限流。LRCLIB 是开放服务，无需密钥。

## 配置（插件管理 › 系统媒体（SMTC））

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 歌词来源 | LRCLIB 优先，网易云音乐补充 | 也可选网易云优先，或只用其中一家 |
| 网易云译文 | 开 | 有翻译时作为译文行 |
| 歌词偏移 | 0 ms | 正值让歌词晚出现；修改后立即生效，不重新搜索 |

来源面板中的媒体会话选择只在本次运行内有效。

## 调试

「调试 › SMTC 与在线歌词」记录以下内容，最多 300 条：

- 会话变化：应用、标题、播放状态；
- 每次搜索的查询内容；
- 候选列表和分数；
- 命中、缓存、手动选择和失败。

「复制诊断信息」会包含最近的记录，但不包含歌词正文。

## 已知限制

- 有些应用不报告时间线，例如部分浏览器页面。这时进度停在 0，时长显示 `--:--`，逐行歌词无法对齐。
- 有些应用的 SMTC 标题带有附加信息，例如「歌名 - 歌手」或「(Live)」。匹配会去掉括号内容，仍可能找错；可以在候选里手动选择。
- 不支持向播放器发送播放、暂停或拖动控制（只读）。

## 验证

- `npx vitest run tests/lyrics-online.test.ts tests/smtc.test.ts` 覆盖以下内容：
  - 匹配、合并译文和选择逻辑；
  - adapter 的进度外推、暂停处理、防抖搜索、缓存和偏移；
  - 未选中时不联网。
- `cargo test --release smtc -- --ignored --nocapture` 在本机读取当前会话，并验证 HTTP 白名单。
- 原生端到端测试：
  1. `qa/smtc/fake-session.ps1` 用静音的 WinRT MediaPlayer 发布一个「夜に駆ける — YOASOBI」会话（261 秒）。
  2. 隔离启动的 release 版选择「系统媒体」后：
     - 自动选中网易云的同步歌词（含译文）；
     - 进度跟随会话；
     - 手动切换候选生效；
     - 调试页记录完整。
