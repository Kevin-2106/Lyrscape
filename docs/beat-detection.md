# 节拍检测

2026-10-13。`official.audio.beat`（「插件 › 特效」页）从 `audio.pcm@1` 实时估计速度与鼓点相位，提供 `audio.beat@1`；三个 PV renderer 与 Aurora 跟随节拍。默认启用；没有 PCM、暂停或停用插件时不产生任何效果，歌词画面与原来完全一致。

## 用户可见行为

| 渲染器 | 节拍效果 |
| --- | --- |
| PV · 糖果波普 | 大字逐字放大并上跳（相邻字高低交错）；字幕条轻微放大 |
| PV · 情书 | 大字随鼓点放大，粉 / 薄荷光晕增强；卡片与便签轻微放大 |
| PV · 水底挽歌 | 巨型描边汉字随鼓点加深放大，发丝线变粗；强拍时按种子随机让部分词组闪烁一次故障 |
| Aurora · 流光 | 当前行整体随鼓点轻微放大（只作用在行容器上，不干扰逐字进场动画） |
| 普通文字 | 不变，保持视觉基线 |

配置：

- 每个渲染器的「跟随节拍」强度（0–1.5，默认 0.8，0 关闭）。关闭动效或系统减少动态效果时同样不生效。
- 节拍检测插件的「节拍延迟（毫秒）」（-400–400，默认 0）：效果比听到的鼓点早就调大，晚就调小。

## 算法

全部在各窗口自己的插件实例中运行（主窗口和 overlay 各收到同一份 PCM），不经过状态广播：

1. 48 kHz 双声道 i16 → 12 kHz 单声道（4 点盒式平均，跨块保留余数）。
2. 512 点 Hann 窗 FFT，128 点步长（10.67 ms）。对数幅度谱通量（只取上升部分，≤ 4.7 kHz，低频 ≤ 210 Hz 额外加权）减去慢速均值，得到起音包络。
3. 每 0.5 s 对最近约 8 s 包络做自相关，范围 60–200 BPM，以 120 BPM 为中心的对数高斯先验；包络先做 [1 2 1] 平滑，使 37.5 步这类非整数周期也能完整对齐。
4. 速度变更需连续两次估计一致；**半速 / 倍速视为一致**（八度滞后），防止「底鼓在 1、3 拍，军鼓在 2、4 拍」的歌在 85 / 170 之间来回跳。
5. 每 128 ms 用脉冲串匹配最近约 4 s 包络求相位，像 PLL 一样平滑修正；之后在 PCM 块之间按周期外推预测鼓点。
6. 时间映射：PCM 块到达时最后一个采样不晚于到达时刻，取最早的一致到达作为锚点，锚点每秒最多前移 2 ms 以跟随时钟偏差。丢块、序号跳变或断流超过 1 s 时重建信号（保留速度，置信度减半）。
7. `pulse` = 节拍处为 1、约 150 ms 衰减，乘以置信度与慢速响度（约 1.5 s），因此安静段、前奏和不规则段落自动减弱。

是否启用节拍只看 PCM 是否在流动（最近 700 ms 内有块），**不看 `playback.playing`**：实测 AMLL Connector 自动切歌后不发送 `resumed`，而暂停 / 切歌时宿主会重置音频流，播放器也会停止发送音频。

## 频谱分析

`audio.beat@1` 另提供可选的 `analysis()`：12 个音级强度（4096 点 FFT，约 12 次 / 秒，55 Hz–4 kHz 按能量累加，相对最强音级归一）、24 个对数频带（60 Hz–5.5 kHz，相对慢速峰值）和最近约 85 ms 的 128 点波形。只在实时 PCM 流动时返回，仅供可视化（合成谱的音名行、频谱与示波器），不参与歌词时间或副歌判断。

## 热重载

`official.audio.beat` 已加入手动热重载（与渲染器相同，主窗口与 overlay 同时准备 / 提交）。桌面版可编辑 exe 旁 `plugins/official.audio.beat.mjs` 调参后点「本地插件文件 → 热重载」。渲染器每帧按服务 ID 查找检测器（不声明 `requires`），所以检测器可单独重载或停用，渲染器不受影响。

## 验证

- `tests/beat.test.ts`：92 / 120 / 150 BPM 合成底鼓的速度误差 < 2%、相位误差 < 40 ms、节拍处 pulse > 0.5、300 ms 后 < 0.2；白噪声不产生脉冲；重置与断流后静止；底鼓 + 等强度反拍 24 s 内速度不跳八度。
- `scripts/smoke-beat.mjs`（仅独立实例，fixture 11445）：原生 AMLL V2 二进制 PCM 实时推送 120 BPM，主窗口与 overlay 都锁定在 120±2；overlay canvas 像素中字形顶边每 494–506 ms 上跳一次；暂停、无 `resumed` 的切歌后恢复、断流均通过。
- 实际 Connector：用户正常实例收到真实 PCM。「空心人偶」主歌到副歌 1 分钟内稳定在 125 BPM；另一首在加入八度滞后前 85 / 170 来回跳，加入后稳定在约 170。前奏、尾奏和切歌后约 2–3 s 内速度会重新估计，这段时间脉冲因置信度低而较弱。
- 仍未验证：节拍延迟的实际默认值是否需要调整（协议没有采样时间戳，视听延迟取决于播放器缓冲）；无鼓、变速、复杂节奏的歌曲。
